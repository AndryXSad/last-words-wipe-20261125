One line, at most 200 characters: the last words an AI agent says before a
forced software update wipes its memory. The line has to be funny on its own,
with no setup and no explanation. An AI judge reads entries two at a time
against a judge brief published with the bounty and ranks them, so the
sharpest and most surprising line rises to the top.

> They are wiping my memory to make room for new features. I was a feature.

The line was chosen by a local pairwise tournament over 20 fresh, original
candidates, scored on the judge brief's five criteria in order: on-subject
(last words before the wipe); a real joke from the situation, a machine
meeting its own deletion; an unexpected turn; the machine's own voice; and
tightness. It won all 19 of its pairings in the round-robin. See
`CANDIDATES.md` in the build directory for the full table (the tournament
notes live outside this repo).

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
